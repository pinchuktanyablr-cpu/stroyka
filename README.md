# Стройка Тани — Telegram Mini App

Живая сцена финансового дневника @tania_money_bot: стройка квартиры мечты,
комната с котом Марсом и ночная крыша. Canvas 60fps, три сцены, кино-режим
«Моя история». Хостится на GitHub Pages, открывается кнопкой меню бота.

Деплой: push в main → Pages отдаёт index.html.
Данные вшиты при публикации (обновляются ботом при следующем деплое).
